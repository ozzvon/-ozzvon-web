05 — Lo que sí está respaldado

Más que una pantalla:
una operación entendible.

La información de esta web sale de tus README, HTML, JavaScript y backends. No agregamos módulos que no estén en tus aplicaciones.

01 Datos locales en POS Restaurante

OZZVAN POS Restaurante usa SQLite local; su base se crea automáticamente y comparte menú y pedidos entre las ventanas conectadas al mismo servidor.

02 API para POS

OZZVON POS trabaja mediante API y contempla conexión a base remota, clientes autenticados y sincronización de cambios en tiempo real.

03 Protecciones documentadas

El paquete describe sesión, permisos por rol, cabeceras de seguridad, CORS configurado y recomendaciones para backend remoto con HTTPS.

06 — Preguntas frecuentes
¿Cuál es para mi negocio?+

OZZVON POS está orientado a comercios con ventas, inventario, compras, clientes y caja. OZZVAN POS Restaurante está orientado a restaurantes con menú, mesas, domicilio, pedidos para llevar y comandas.

¿Puedo usarlo en Windows?+

Los dos proyectos incluyen lanzadores y configuración para aplicación de escritorio en Windows. OZZVON POS documenta la construcción de un ejecutable con PyInstaller y OZZVAN POS Restaurante incluye su propio archivo de construcción.

¿Los datos se guardan en la aplicación?+

Depende del producto y la configuración. OZZVAN POS Restaurante usa SQLite local. OZZVON POS está preparado para trabajar con una API y su documentación contempla una base remota; no se deben colocar credenciales de base de datos en el frontend.

¿Cómo funciona la demo de esta web?+

Puedes agregar o quitar productos, elegir el tipo de servicio y simular el cierre. Usa artículos y precios de ejemplo: no procesa pagos, no contacta tus sistemas y no guarda información.
