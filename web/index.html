06 — Resolvemos tus dudas
¿Cuál punto de venta le sirve a mi negocio?+

Si tienes un comercio y quieres organizar ventas, productos, existencias y caja, conoce OZZVON POS. Si atiendes mesas y pedidos para llevar o a domicilio, explora OZZVAN POS Restaurante.

¿Puedo usarlo en una computadora con Windows?+

Sí. Ambos puntos de venta cuentan con una versión para computadora con Windows. Contáctanos para conocer cuál se adapta mejor a tu forma de trabajar.

¿La prueba de esta página afecta los datos de mi negocio?+

No. La prueba usa información de ejemplo y los cambios solo duran mientras exploras la página. No se conecta a tu negocio ni modifica tus productos, ventas o pedidos.

¿Cómo funciona la demo de esta web?+

Puedes probar tareas como agregar productos, cambiar cantidades, elegir el servicio de un pedido y revisar los totales. Se usan datos de ejemplo: no se cobran ventas ni se conservan los cambios.
